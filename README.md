# Bibliotheca+

Sistema full-stack de gestão de biblioteca, com cadastro, autenticação e controle de usuários por perfil.

## Sobre o projeto

O Bibliotheca+ foi desenvolvido para digitalizar e centralizar a rotina de uma biblioteca: cadastro e gerenciamento de acervo, controle de usuários por perfil (estudantes e administração) e todo o fluxo de aluguel de livros, do empréstimo à devolução.

O sistema foi dimensionado para suportar um catálogo de mais de 100 livros.

## Funcionalidades

- Autenticação de usuários
- Controle de acesso por perfil (estudante / administração)
- Cadastro e gerenciamento de livros
- Fluxo completo de aluguel de livros (empréstimo e devolução)

## Tecnologias utilizadas
Frontend: React, Vite
Backend / Banco de dados: Supabase
